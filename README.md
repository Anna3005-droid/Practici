# Практики курса

Практики курса Татьяны Хавро «Масштаб». Каждая практика — отдельная страница со своим адресом, друг на друга они не ссылаются. Прогресс хранится на телефоне, всё работает без интернета, и каждую практику можно поставить на главный экран отдельной иконкой.

- **Проработка эмоций** — адрес сайта без добавок (`index.html`). Шкала эмоций Метода Седоны: девять кластеров от Апатии до Мира, отметки проработанных состояний, счётчик за день и общий прогресс.
- **Проработка вторичных выгод** — адрес сайта + `/vygody.html`. Три вопроса, к каждому свой проговор. Места, где нужно подставить свои слова, выделены рамкой, паузы «Вдох-выдох» — отдельной строкой. Можно выбрать «Она» или «Он», и слова вроде «свободен/на» станут в нужном роде.

## Файлы

Все файлы лежат в корне репозитория, без папок:

- `index.html` — проработка эмоций
- `vygody.html` — проработка вторичных выгод
- `manifest.webmanifest`, `vygody.webmanifest` — данные для установки на телефон, у каждой практики свои
- `sw.js` — работа без интернета
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — иконки

## Как опубликовать

1. На [vercel.com](https://vercel.com) нажмите **Add New → Project**.
2. Выберите репозиторий **Practici** и нажмите **Import**.
3. Ничего не меняйте и нажмите **Deploy**.

После каждого изменения в репозитории Vercel сам обновит сайт примерно за минуту.

## Как поставить на телефон

Откройте нужную практику по её адресу, дальше:

- **Android (Chrome):** откройте сайт → меню ⋮ → **Добавить на главный экран**.
- **iPhone (Safari):** откройте сайт → кнопка **Поделиться** → **На экран «Домой»**.

## Если поменяли файлы

В `sw.js` увеличьте номер в строке `var VERSION = 'emo-v7';` (например, на `emo-v8`). Тогда телефоны получат новую версию, а не сохранённую старую. Новую страницу добавьте ещё и в список `APP` там же, чтобы она открывалась без интернета.
