# Практики

Приложение с двумя практиками, между ними можно переключаться кнопками наверху:

- **Проработка эмоций** — шкала эмоций Метода Седоны: девять кластеров от Апатии до Мира, отметки проработанных состояний, счётчик за день и общий прогресс.
- **Обработка полярностей** — протокол «Слив»: инструкция для подсознания, 428 пар полярностей по алфавиту, порции по 10–15 пар, кнопка «Пропустить» для непонятных пар, свои личные полярности и поиск по списку.

Прогресс каждой практики хранится на телефоне отдельно, приложение работает без интернета и ставится на главный экран.

## Файлы

Все файлы лежат в корне репозитория, без папок:

- `index.html` — практика «Проработка эмоций» (открывается первой)
- `polarities.html` — практика «Обработка полярностей»
- `style.css` — общий дизайн обеих практик
- `manifest.webmanifest` — данные для установки на телефон
- `sw.js` — работа без интернета
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — иконки

## Как опубликовать

1. На [vercel.com](https://vercel.com) нажмите **Add New → Project**.
2. Выберите репозиторий **Practici** и нажмите **Import**.
3. Ничего не меняйте и нажмите **Deploy**.

После каждого изменения в репозитории Vercel сам обновит сайт примерно за минуту.

## Как поставить на телефон

- **Android (Chrome):** откройте сайт → меню ⋮ → **Добавить на главный экран**.
- **iPhone (Safari):** откройте сайт → кнопка **Поделиться** → **На экран «Домой»**.

## Если поменяли файлы

В `sw.js` увеличьте номер в строке `var VERSION = 'emo-v6';` (например, на `emo-v7`). Тогда телефоны получат новую версию, а не сохранённую старую.

Если добавляете новую страницу-практику, впишите её имя в список `APP` в том же файле, чтобы она открывалась без интернета.
