# Практики

Две отдельные практики, у каждой своя ссылка. Они не ссылаются друг на друга, и каждая ставится на телефон отдельным приложением со своим значком:

| Практика | Ссылка | Значок на телефоне |
|---|---|---|
| **Проработка эмоций** — шкала эмоций Метода Седоны: девять кластеров от Апатии до Мира, отметки проработанных состояний, счётчик за день и общий прогресс | `адрес-сайта/` | «Эмоции» |
| **Обработка полярностей** — протокол «Слив»: инструкция для подсознания, 428 пар полярностей по алфавиту, порции по 10–15 пар, кнопка «Пропустить» для непонятных пар, свои личные полярности и поиск по списку | `адрес-сайта/polarities.html` | «Полярности» |

`адрес-сайта` — адрес, который выдал Vercel (например, `practici.vercel.app`). Прогресс каждой практики хранится на телефоне отдельно, обе работают без интернета.

## Файлы

Все файлы лежат в корне репозитория, без папок:

- `index.html` — практика «Проработка эмоций»
- `polarities.html` — практика «Обработка полярностей»
- `style.css` — общий дизайн обеих практик
- `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — установка «Эмоций» на телефон и их значок
- `manifest-polarities.webmanifest`, `icon-pol-192.png`, `icon-pol-512.png`, `apple-touch-icon-pol.png` — установка «Полярностей» на телефон и их значок
- `sw.js` — работа без интернета для обеих практик

## Как опубликовать

1. На [vercel.com](https://vercel.com) нажмите **Add New → Project**.
2. Выберите репозиторий **Practici** и нажмите **Import**.
3. Ничего не меняйте и нажмите **Deploy**.

После каждого изменения в репозитории Vercel сам обновит сайт примерно за минуту.

## Как поставить на телефон

Откройте ссылку нужной практики, затем:

- **Android (Chrome):** меню ⋮ → **Добавить на главный экран**.
- **iPhone (Safari):** кнопка **Поделиться** → **На экран «Домой»**.

Чтобы на телефоне были обе практики, повторите это для каждой ссылки.

## Если поменяли файлы

В `sw.js` увеличьте номер в строке `var VERSION = 'emo-v7';` (например, на `emo-v8`). Тогда телефоны получат новую версию, а не сохранённую старую.

Если добавляете новую страницу-практику, впишите её имя в список `APP` в том же файле, чтобы она открывалась без интернета.
