# Практики курса

Практики курса Татьяны Хавро «Масштаб». Прогресс хранится на телефоне, всё работает без интернета и ставится на главный экран.

- **Проработка эмоций** (`index.html`) — шкала эмоций Метода Седоны: девять кластеров от Апатии до Мира, отметки проработанных состояний, счётчик за день и общий прогресс.
- **Проработка вторичных выгод** (`vygody.html`) — три вопроса, к каждому свой проговор. Места, где нужно подставить свои слова, выделены рамкой, паузы «Вдох-выдох» — отдельной строкой. Можно выбрать «Она» или «Он», и слова вроде «свободен/на» станут в нужном роде.

## Файлы

Все файлы лежат в корне репозитория, без папок:

- `index.html` — проработка эмоций
- `vygody.html` — проработка вторичных выгод
- `manifest.webmanifest` — данные для установки на телефон
- `sw.js` — работа без интернета
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — иконки

## Как опубликовать

1. На [vercel.com](https://vercel.com) нажмите **Add New → Project**.
2. Выберите репозиторий **Practici** и нажмите **Import**.
3. Ничего не меняйте и нажмите **Deploy**.

После каждого изменения в репозитории Vercel сам обновит сайт примерно за минуту.

## Как поставить на телефон

- **Android (Chrome):** откройте сайт → меню ⋮ → **Добавить на главный экран**.
- **iPhone (Safari):** откройте сайт → кнопка **Поделиться** → **На экран «Домой»**.

## Если поменяли файлы

В `sw.js` увеличьте номер в строке `var VERSION = 'emo-v6';` (например, на `emo-v7`). Тогда телефоны получат новую версию, а не сохранённую старую. Новую страницу добавьте ещё и в список `APP` там же, чтобы она открывалась без интернета.
