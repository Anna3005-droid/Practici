# Практики

Каждая практика — отдельный сайт со своим адресом. Сайты не ссылаются друг на друга, у каждого свой прогресс, и каждый ставится на телефон отдельным приложением со своим значком.

| Сайт | Где лежит | Значок на телефоне |
|---|---|---|
| **Проработка эмоций** — шкала эмоций Метода Седоны: девять кластеров от Апатии до Мира, отметки проработанных состояний, счётчик за день и общий прогресс | корень репозитория | «Эмоции» |
| **Обработка полярностей** — протокол «Слив»: инструкция для подсознания, 428 пар полярностей по алфавиту, порции по 10–15 пар, кнопка «Пропустить», свои личные полярности и поиск | папка `polyarnosti` | «Полярности» |
| **Метафорические карты** — рандомайзер колоды МАК: запрос, 1 или 3 карты случайно или из веера рубашкой вверх, карты не повторяются до конца колоды, вопросы к карте, дневник раскладов | папка `karty` | «Карты» |

## Зеркала на GitHub Pages

У каждого сайта два адреса с одинаковым содержимым:

| Сайт | Vercel | GitHub Pages (зеркало) |
|---|---|---|
| Проработка эмоций | https://emotional-pi.vercel.app/ | https://anna3005-droid.github.io/Practici/ |
| Обработка полярностей | https://practici-polyarnosti.vercel.app/ | https://anna3005-droid.github.io/Practici/polyarnosti/ |
| Метафорические карты | https://practici-karty.vercel.app/ | https://anna3005-droid.github.io/Practici/karty/ |

Зеркала нужны тем, у кого не открываются адреса на vercel.app: у части мобильных операторов в России, Турции, Бангладеш и других странах адреса Vercel недоступны, а GitHub Pages открывается. Ничего отдельно обновлять не нужно: после каждого изменения основной ветки файл `.github/workflows/pages-mirror.yml` сам копирует её в ветку `gh-pages`, и через пару минут зеркала обновляются. Ветку `gh-pages` руками не трогайте.

На GitHub Pages все три сайта живут на одном адресе, поэтому каждый `sw.js` при обновлении удаляет только свои сохранённые копии (по своей приставке `emo-`, `pol-`, `mak-`), а `sw.js` в корне не трогает папки других сайтов. Если будете добавлять новый сайт в папку, дайте его `sw.js` свою приставку.

## Файлы

Сайт «Проработка эмоций» — файлы в корне репозитория:

- `index.html` — само приложение
- `manifest.webmanifest` — данные для установки на телефон
- `sw.js` — работа без интернета
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — иконки

Сайт «Обработка полярностей» — всё в папке `polyarnosti`:

- `index.html` — само приложение
- `style.css` — дизайн
- `manifest.webmanifest` — данные для установки на телефон
- `sw.js` — работа без интернета
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — иконки

Сайт «Метафорические карты» — всё в папке `karty`:

- `index.html` — само приложение
- `style.css` — дизайн
- `cards.js` — список встроенных карт
- `cards/` — картинки встроенных карт: акварельные `karta-01.jpg` … `karta-55.jpg` и абстрактные `abstr-01.jpg` … `abstr-81.jpg`
- `manifest.webmanifest` — данные для установки на телефон
- `sw.js` — работа без интернета, вместе с картинками карт
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — иконки

## Как добавить карты в колоду

1. Загрузите картинки в папку `karty/cards` (на GitHub: откройте папку → **Add file → Upload files**).
2. В файле `karty/cards.js` допишите их имена в список, каждое в кавычках и с запятой, например `'karta-56.jpg',`.
3. В `karty/sw.js` увеличьте номер версии (см. ниже).

На самом сайте добавить карты нельзя: колоду меняет только владелец, через этот репозиторий.

## Как опубликовать

Каждый сайт — отдельный проект на Vercel. Все берутся из этого же репозитория, отличаются только папкой.

**Проработка эмоций** (корень репозитория):

1. На [vercel.com](https://vercel.com) нажмите **Add New → Project**.
2. Выберите репозиторий **Practici** и нажмите **Import**.
3. Ничего не меняйте и нажмите **Deploy**.

**Обработка полярностей** (папка `polyarnosti`):

1. На [vercel.com](https://vercel.com) нажмите **Add New → Project**.
2. Выберите тот же репозиторий **Practici** и нажмите **Import**.
3. В поле **Project Name** впишите название, например `polyarnosti`. Из него получится адрес сайта.
4. Рядом с **Root Directory** нажмите **Edit**, выберите папку **polyarnosti** и нажмите **Continue**.
5. Нажмите **Deploy**.

**Метафорические карты** (папка `karty`): так же, как полярности, только в поле **Project Name** впишите, например, `karty`, а в **Root Directory** выберите папку **karty**.

После каждого изменения в репозитории Vercel сам обновит все сайты примерно за минуту.

## Как поставить на телефон

Откройте адрес нужного сайта, затем:

- **Android (Chrome):** меню ⋮ → **Добавить на главный экран**.
- **iPhone (Safari):** кнопка **Поделиться** → **На экран «Домой»**.

## Если поменяли файлы

В файле `sw.js` того же сайта увеличьте номер версии в строке `var VERSION = PREFIX + 'v…';`: сейчас в корне это `'v9'`, в папке `polyarnosti` — `'v2'`, в папке `karty` — `'v8'` (например, `'v9'` → `'v10'`). Тогда телефоны получат новую версию, а не сохранённую старую.
