# Проработка эмоций

Приложение со шкалой эмоций Метода Седоны: девять кластеров от Апатии до Мира, отметки проработанных состояний, счётчик за день и общий прогресс. Прогресс хранится на телефоне, приложение работает без интернета и ставится на главный экран.

## Файлы

Файлы «Проработки эмоций» лежат в корне репозитория:

- `index.html` — само приложение
- `manifest.webmanifest` — данные для установки на телефон
- `sw.js` — работа без интернета
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — иконки

## Как опубликовать

1. На [vercel.com](https://vercel.com) нажмите **Add New → Project**.
2. Выберите репозиторий **Practici** и нажмите **Import**.
3. Ничего не меняйте и нажмите **Deploy**.

После каждого изменения в репозитории Vercel сам обновит сайт примерно за минуту.

## Как поставить на телефон

- **Android (Chrome):** откройте сайт → меню ⋮ → **Добавить на главный экран**.
- **iPhone (Safari):** откройте сайт → кнопка **Поделиться** → **На экран «Домой»**.

## Если поменяли файлы

В `sw.js` увеличьте номер в строке `var VERSION = 'emo-v1';` (например, на `emo-v2`). Тогда телефоны получат новую версию, а не сохранённую старую.

## Второй сайт: «Проработка вторичных выгод»

Лежит в папке `vygody`. Это отдельный сайт: у него свой адрес, своя иконка на телефоне («Выгоды») и своя работа без интернета. С «Проработкой эмоций» он не связан.

Три вопроса, к каждому свой проговор. Места, где нужно подставить свои слова, выделены рамкой, паузы «Вдох-выдох» стоят отдельной строкой. Можно выбрать «Она» или «Он», и слова вроде «свободен/на» станут в нужном роде.

### Как опубликовать

1. На [vercel.com](https://vercel.com) нажмите **Add New → Project**.
2. Снова выберите репозиторий **Practici** и нажмите **Import**.
3. В поле **Project Name** напишите, например, `vygody`. От этого названия зависит адрес сайта.
4. Рядом с **Root Directory** нажмите **Edit**, выберите папку `vygody` и нажмите **Continue**.
5. Нажмите **Deploy**.

### Если поменяли файлы в папке `vygody`

В `vygody/sw.js` увеличьте номер в строке `var VERSION = 'vyg-v1';` (например, на `vyg-v2`).
